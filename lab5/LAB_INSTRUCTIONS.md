Welcome to Lab 5!

Lab 5 is split into 3 sub projects. They get successively harder, so try
starting with the first. To receive full credit, attempt to complete at least
the one challenge of each of the 3 before submitting the ZIP file.

Each Lab Project has further instructions inside of them.




NOTE: The solution app folder index.html will require use of a web server such as
Simple Web Server, or any dev server that comes with an IDE or framework. However, it
will NOT require the use of NPM or Node.js -- so you can try out the app even if 
you can't get everything else working. There are also several videos.

NOTE: Remember that it's okay to not complete them. That's because the only
requirement is to attempt one challenge in each project - something you likely
will be able to do during class time. If you at least attempt (even if not
complete) each of the lab projects, then you will receive full credit. Of
course, if you complete more for practice, that's up to you!
